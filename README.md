# 🌦️ Weather Monitoring System

## 📖 Overview

The Weather Monitoring System is an IoT-based project designed to monitor environmental conditions in real time. It collects temperature and humidity data using sensors and uploads the information to Firebase through the ESP8266 Wi-Fi module for remote monitoring.

---

## 🚀 Features

- Real-time temperature monitoring
- Real-time humidity monitoring
- Wireless data transmission using ESP8266
- Firebase cloud integration
- IoT-based remote monitoring
- Low-cost and energy-efficient solution

## ⚙️ Working

1. The DHT11 sensor measures temperature and humidity.
2. ESP8266 processes the sensor data.
3. Data is transmitted to Firebase over Wi-Fi.
4. Users can monitor the readings remotely through Firebase.
